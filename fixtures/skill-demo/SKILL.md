# 周报生成器

把用户提供的一周工作记录（聊天记录、待办清单、commit 日志均可）整理为周报草稿。

## 输出格式

1. **本周完成**：3-5 条，每条一句话，尽量带可量化结果；
2. **进行中**：注明当前进度百分比与下一步动作；
3. 风险与需要的支持**：没有就写「无」；
4. **下周计划**：3 条以内，按优先级排序。

## 规则

- 不编造用户未提供的数据；
- 语气平实，不用形容词堆砌；
- 控制在 400 字以内。

## 使用

运行 `scripts/weekly.py` 可将纯文本记录转换为三段式草稿（离线可用，无第三方依赖）。
